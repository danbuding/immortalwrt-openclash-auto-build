# ImmortalWrt + OpenClash 一键编译脚本

## 📝 简介

这是一个专为 **Debian 13 (Trixie)** 环境打造的 ImmortalWrt 编译自动化脚本。它整合了环境部署、源码拉取、OpenClash 插件集成、Feeds 更新以及编译等全套流程，旨在帮助你从零开始，用最少的干预生成带 OpenClash 的软路由固件。

## 💻 适用环境

*   **宿主系统**：PVE KVM 虚拟机（推荐，兼容性最好）。
*   **操作系统**：纯净安装的 Debian 13 (Trixie)。
*   **硬件要求**：建议分配至少 4 核 CPU。**强烈建议分配 4GB 以上内存**。
*   **运行用户**：普通用户（需具备 `sudo` 权限），**严禁直接使用 root 运行**。

## ✨ 核心特性（防坑指南）

*   **一键换源**：内置阿里云、上海交大、清华源，解决国内网络拉取慢的问题。
*   **静默安装依赖**：通过 `DEBIAN_FRONTEND=noninteractive` 强制关闭类似 `msmtp` 的配置弹窗，拒绝卡死。
*   **极速克隆**：采用 `--depth 1` 浅克隆 ImmortalWrt 和 OpenClash，大幅缩短下载时间。
*   **防 403 容错**：在预下载阶段（`make download`），如果并发过高导致部分包下载失败，会自动降级为单线程重试。
*   **自动集成 OpenClash**：直接将插件代码放入 `package/` 目录，并在编译前强校验是否选中。
*   **内存保护提示**：针对小内存虚拟机，在编译前给出明确的内存崩溃预警。

## 🚀 快速开始

### 1. 准备脚本

将一键脚本保存到你的用户目录下，命名为 `build-openwrt.sh`。

### 2. 赋予执行权限

在终端中运行以下命令：

    chmod +x build-openwrt.sh

### 3. 启动编译

直接以普通用户身份运行（**绝对不要加 `sudo`**）：

    ./build-openwrt.sh

### 4. 跟随向导操作

1.  **选择源**：根据提示输入数字（上海电信推荐选 1 阿里云 或 2 上海交大）。
2.  **等待依赖和拉取**：脚本会自动安装依赖并克隆源码，期间无需干预。
3.  **手动配置（make menuconfig）**：
    *   进入图形界面后，选择你的路由器架构（如 `x86`）和具体型号。
    *   导航到 `LuCI -> Applications -> luci-app-openclash`，按 `Y` 键使其显示为 `*`。
    *   保存（Save）并退出（Exit）。
4.  **自动编译**：退出配置界面后，脚本会自动校验并接管后续的 `make` 编译过程。

## ⚠️ 重要提醒（必看）

**关于内存爆满（Killed）的解决方案：**

由于编译过程（尤其是 `cc1` 进程）极其吃内存，如果你在 PVE 中给虚拟机分配的内存较小（例如只有 2.5GB），在脚本自动执行 `make -j$(nproc)` 时，极大概率会因为内存不足被系统强制终止（终端提示 `Killed`）。

**如果发生中断，请不要慌，直接在终端输入以下命令即可继续：**

    make -j2 V=s

将并发数降到 2，就能在有限的内存下慢慢跑完编译，只是耗时会更长。

## 📂 编译产物在哪？

编译成功后，终端会打印出固件的生成路径。通常位于源码目录下的：

    bin/targets/<平台架构>/<子平台>/

对于 x86 软路由，主要寻找 `*-squashfs-combined-efi.img.gz` 或 `*-squashfs-sysupgrade.bin` 文件即可。
